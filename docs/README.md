# Curation and Retrieval Documentation

This folder is split by audience. Use both when you need to run the product
and change it.

## If you want to run curation and retrieval

Start with the [User Guide](user-guide/README.md). That path covers install,
the first cookbook run, sample clips, endpoints, and troubleshooting.

Recommended order:

1. [Installation](user-guide/installation.md)
2. [Getting Started](user-guide/getting-started.md)
3. [Samples and Cookbooks](user-guide/samples-and-cookbooks.md)

## If you want to change this repository

Start with [Developer Docs](developer/README.md). That path covers architecture
and contributor layout.

## Canonical folders

- [User Guide](user-guide/README.md) — product documentation for customers
- [Developer Docs](developer/README.md) — contributor documentation
- [Assets](assets/) — architecture diagrams
- [Cookbooks](../cookbook/README.md) — scenario configs and runbooks
